## 1정규화(1NF)

\= 하나의 도메인에는 하나의 원자값이 들어가야한다.

조건 : 1속성 1원자

1개 속성에 여러 값이 배열 형태처럼 들어갈 수 있다면 위반

> **Hint:**&#x20;
>
> 도메인 : 속성에 들어갈 값의 유효범위
>
> 원자값&#x20;
{% endstep %}

{% step %}
## **2정규화(2NF)**

-부분적 함수종속 : 식별관계를 가지는 테이블에서 복합키의 일부분으로만 식별되는 속성들

조건 :  super PK일 때 (식별자 상태)

super PK의 키가 아닌 타 속성이 종속되어 있으면 2정규화 위반

[해결방법 : 부모한테 속성 쫓아내기](#user-content-fn-1)[^1]

{% hint style="info" %}
식별관계 : primarykey가 부모의 아이디 인 친구들
{% endhint %}
{% endstep %}

{% step %}
## **3정규화(3NF)**

이행적 함수 종속을 없애는 것

조건 : 테이블이 종속되어 FK존재

이 때 데이터 FK의 키가 아닌 데이터(속성)가 종속되어 있는 경우 위반

해결방법 : 부모한테 속성 쫓아내기

{% hint style="info" %}
-이행적 함수 종속 : 두 번 이상의 참조를 통해서 식별되는 속성들
{% endhint %}
{% endstep %}
