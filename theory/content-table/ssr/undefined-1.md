서버는 어려움

### 클라이언트와 서버의 상태관리 차이

클라이언트 사이드는 새로고침이 일어나지 않는 한 상태를 쉽게 유지할 수 있습니다. 반면, 서버는 각 요청마다 독립적으로 처리하기 때문에 상태 관리가 복잡합니다.

### 쿠키의 역할과 작동 방식

쿠키는 서버가 만들어 클라이언트(브라우저)에게 보내는 작은 데이터 조각입니다:

* **생성 주체**: 서버
* **보관 주체**: 클라이언트(브라우저)
* **작동 방식**:
  1. 서버가 응답 시 Set-Cookie 헤더로 쿠키 생성 지시
  2. 브라우저가 쿠키 저장
  3. 이후 요청 시 브라우저가 자동으로 쿠키를 요청에 포함
  4. 서버는 이 쿠키를 통해 이전 요청의 맥락 파악 가능

이렇게 서버는 저장 공간이 없음에도 클라이언트를 통해 상태를 유지할 수 있습니다
